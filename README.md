# AI Personalised Learning Mobile Application

This project is an AI-driven mobile application designed to generate personalised learning pathways using machine learning techniques.

---

# Overview
The application analyses user preferences, skills, and interests to recommend tailored learning content.  
It combines a mobile frontend with a backend API and machine learning models.

---

# Features
- Personalised learning recommendations  
- User clustering using K-Means algorithm  
- Mobile application built with Flutter  
- Backend API developed with Flask  
- Data-driven decision-making system  

---

# Technologies Used
- Python  
- Flask (Backend API)  
- Flutter (Mobile Frontend)  
- Machine Learning (scikit-learn)  
- REST APIs  

---

# Project Structure
- `/frontend` – Flutter mobile application  
- `/backend` – Flask API and ML models  
- `/demo` – Demo files
